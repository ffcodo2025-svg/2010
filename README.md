# Chúc mừng 20/10 ♡

Web thiên hà – hành tinh – trái tim hạt sáng, chạy tốt trên iPhone / Android / iPad.

## Cấu trúc
- `index.html` – khung trang
- `css/style.css` – giao diện, nền thiên hà bằng CSS
- `js/config.js` – **nơi sửa tên, thư, link nhạc**
- `js/main.js` – hiệu ứng 3D (Three.js)
- `favicon.svg` – biểu tượng tab

## Đưa lên GitHub Pages
1. Tạo repo mới, upload **toàn bộ** các file/thư mục trên (giữ nguyên thư mục `css`, `js`).
2. Settings → Pages → Source: `Deploy from a branch` → Branch `main` / `(root)` → Save.
3. Mở link `https://<tên-bạn>.github.io/<tên-repo>/` sau ~1 phút.

## Nhạc
Mở `js/config.js`, dán link catbox vào `music` (ví dụ `https://files.catbox.moe/abc123.mp3`).
